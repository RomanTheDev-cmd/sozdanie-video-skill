# Подключение VideoFreeLearn

Один источник интерфейса — iCloud `Служебное/Общие навыки/videofreelearn`. Символические ссылки Codex/Claude указывают на него. В плагине хранится небольшой загрузчик: он читает этот источник при вызове, поэтому его копия не является отдельным набором правил производства.

Движок — общий `freelearn-video`, найденный через согласованные ссылки `~/.codex/skills/freelearn-video` и `~/.claude/skills/freelearn-video`. Эти пути сохранены для совместимости скриптов; SKILL.md у движка отсутствует, поэтому отдельным навыком он не регистрируется. Инструкции — ENGINE.md от корня движка. При создании наблюдалась версия 1.3.5; это не закрепление будущих версий. status показывает фактически прочитанную версию и пути. Отсутствующие/разошедшиеся ссылки означают невыполнимость локального этапа в текущей среде, а не невозможность вообще.

Новое окружение и новые веса не нужны: интерфейс — Python stdlib, зависимости производства остаются у движка в `~/.local/share/freelearn-video`, кэш/веса — `~/.cache/freelearn-video`. Для runtime действует существующий `FREELEARN_VIDEO_RUNTIME`. Ничего из этого не копировать в iCloud или ZIP плагина.

`engine.py check-entrypoint` запускает постоянные проверки самого интерфейса на временных данных; дочерние команды внутри тестов подменены. Движок и его окружения для этой команды не нужны. `engine.py check` выполняет тот же набор первым, затем регрессии найденного движка; при ошибке первого этапа второй не запускается. `check-audio` отдельно проверяет входы/математику аудио движка. Результаты слоёв указывать раздельно.

Plugin Creator сохраняет приватный skills-only пакет. Сохранение пакета не подтверждает установку/активацию в чате или запуск видео. На облачном хосте без локального источника и процессов доступна подготовка сценария; рендер не обещается. Если загрузчик не может прочитать общий навык, назвать отсутствующий путь и остановить локальный этап.

Публичная публикация, загрузка медиа/книги, изменение аудитории плагина и установка новых зависимостей не входят в этот интерфейс. Для отчёта и протоколов используется папка проверок в проекте FreeLearn; результат проверок привязывается к фактическим источникам, а не к их mtime.

После изменения пакета отдельно читать сохранённые manifest, загрузчик и знак через Plugin Creator. Создание 1.0.0 подставило данные профиля в author/developerName; обновление 1.0.1 с явным FreeLearn без email сохранило бренд в обоих manifest. Это проверено для данного релиза, не гарантия будущего сохранения или вида карточки в интерфейсе. Профиль аккаунта и аудиторию ради этого не менять.
